<Info>
  **Resumo:** a seção `BASIC_INFORMATION` reúne os dados cadastrais. Também chega **fragmentada** (7 fragmentos no relatório verificado), com cada fonte contribuindo o seu bloco.
</Info>

<Warning>
  **Não há exemplo completo desta seção nesta página, de propósito.** O payload real é grande demais: chega em 7 fragmentos de `sectionDetails` e inclui o retorno bruto de cada fonte cadastral. Um dump inteiro seria ilegível e envelheceria rápido.

  O que está abaixo é um **trecho real**, anonimizado, para você reconhecer o formato. Para o payload completo do seu caso, chame [`GET /report/{id}/section/{sectionType}`](/api-reference/report/get-report-section) com o seu relatório. Para a leitura já interpretada, sem lidar com o bruto, use [`GET /report/{id}/insights`](/api-reference/report/get-reportinsights).
</Warning>

### Trecho real

```json
{
  "name": "EMPRESA EXEMPLO S/A",
  "legalName": "EMPRESA EXEMPLO S/A",
  "document": "43.591.367/0001-30",
  "status": "SUSPENSA",
  "mainActivity": {
    "code": "",
    "activity": ""
  }
}
```

## Cadastro da empresa

| Campo | Tipo | Descrição |
|---|---|---|
| `name` | string | Nome ou razão social. |
| `legalName` | string | Razão social. |
| `document` | string | Documento **formatado** (ex.: `"43.591.367/0001-30"`). |
| `status` | string | Situação cadastral (ex.: `"SUSPENSA"`). |
| `mainActivity` | object | CNAE principal: `{ code, activity }`. |
| `secondaryActivities` | object[] | CNAEs secundários. |

## Contatos e endereço

| Campo | Tipo | Descrição |
|---|---|---|
| `lemitPrimaryAddress` | object | Endereço principal: `{ address, creationDate }`. |
| `lemitPrimaryPhoneNumber` | string | Telefone principal. |
| `lemitPrimaryEmail` | string | E-mail principal. |
| `lemitSecondaryContacts` | object[] | Contatos secundários. |
| `lemitProfession` | string | Profissão (PF). |
| `cPFSituation` | string | Situação do CPF (PF). |

## Vínculos e metadados

| Campo | Tipo | Descrição |
|---|---|---|
| `historyRelationships` | object[] | Histórico de relacionamentos societários. |
| `document` | string | Documento sem formatação, no fragmento de origem. |
| `yearMonth` | number | Competência dos dados (`AAAAMM`). |
| `metadata` | object | Metadados da consulta na fonte. |
| `id`, `createdAt`, `updatedAt` | | Identificação do registro de origem. |

<Note>
  Repare que `document` aparece **formatado num fragmento e sem formatação em outro**, conforme a fonte. Normalize antes de comparar.
</Note>
