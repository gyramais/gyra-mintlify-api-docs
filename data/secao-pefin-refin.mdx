## Campos reais da seção

Os dados ficam em `sectionDetails[].values.{provedor}`. `PEFIN` e `REFIN` são **seções separadas**, com a mesma forma e prefixos próprios.

### Pefin

| Campo | Tipo | Descrição |
|---|---|---|
| `injunction` | boolean | Indica liminar sobre as pendências. |
| `financialPendenciesQuantity` | number | Quantidade de pendências financeiras. |
| `financialPendenciesTotalValue` | string | Valor total, **já formatado** em reais. |
| `lastPefinDate` | string | Data da ocorrência mais recente (crua). |
| `formattedLastPefinDate` | string | A mesma data formatada. |
| `pefinTable` | object[] | Lista das pendências. Campos abaixo. |

### `pefinTable[]`

| Campo | Tipo | Descrição |
|---|---|---|
| `name` | string | Nome do titular do documento analisado. |
| `type` | string | Papel na dívida: `"Devedor Principal"` ou `"Avalista"`. |
| `creditor` | string | Nome do credor. |
| `date` | date | Data da ocorrência (crua). |
| `formattedDate` | string | A mesma data formatada. |
| `value` | number | Valor da pendência (cru). |
| `uf` | string | Unidade federativa. |

### Refin

Mesma estrutura, com os campos correspondentes de refinanciamento (`lastRefinDate`, `formattedLastRefinDate`, `refinTable`).

<Warning>
  O conjunto de campos **depende do provedor** que respondeu. Ver [Estrutura do Relatório](/data/estrutura-relatorio#onde-ficam-os-dados-sectiondetails-values).
</Warning>
