<Info>
  **Resumo:** `PEP` e `SANCTIONS` são **duas seções separadas**, cada uma com os dados do titular e dos sócios em fragmentos distintos.
</Info>

<Warning>
  **Não há exemplo completo desta seção nesta página, de propósito.** O payload real é grande demais: os achados de PEP e de sanções vêm em fragmentos separados e cada achado traz o registro completo da fonte. Um dump inteiro seria ilegível e envelheceria rápido.

  O que está abaixo é um **trecho real**, anonimizado, para você reconhecer o formato. Para o payload completo do seu caso, chame [`GET /report/{id}/section/{sectionType}`](/api-reference/report/get-report-section) com o seu relatório. Para a leitura já interpretada, sem lidar com o bruto, use [`GET /report/{id}/insights`](/api-reference/report/get-reportinsights).
</Warning>

## Seção `PEP`

| Campo | Tipo | Descrição |
|---|---|---|
| `id` | string | Identificador no formato `AAAAMM-documento`. |
| `document` | string | Documento consultado, sem formatação. |
| `yearMonth` | number | Competência dos dados (`AAAAMM`). |
| `kyc` | object[] | Achados de PEP do próprio documento. |
| `ownersKyc` | object[] | Achados de PEP dos sócios. |
| `createdAt` / `updatedAt` | datetime | Datas do registro. |

`kyc` e `ownersKyc` vêm em **fragmentos separados** de `sectionDetails`.

## Seção `SANCTIONS`

| Campo | Tipo | Descrição |
|---|---|---|
| `national` | object[] | Sanções nacionais do documento analisado. |
| `international` | object[] | Sanções internacionais do documento analisado. |
| `ownersNational` | object[] | Sanções nacionais dos sócios. |
| `ownersInternational` | object[] | Sanções internacionais dos sócios. |

Também em dois fragmentos: um com os dados do documento e outro com os dos sócios.

<Warning>
  Presença nessas listas **não significa sanção efetiva**. São achados de screening que precisam de conferência de identidade. Para a leitura já interpretada, use o [parecer da seção](/api-reference/report/get-reportinsights).
</Warning>
