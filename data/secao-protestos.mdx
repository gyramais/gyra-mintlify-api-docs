A seção `PROTESTS` traz os protestos em cartório registrados para o documento. A **fonte** dos dados é configurável na política, e isso afeta a abrangência geográfica do retorno.

Disponível no relatório **COMPLETO** e **COMPLETO+**.

## Campos reais da seção

Os dados ficam em `sectionDetails[].values.{provedor}`. Estrutura confirmada para o provedor Serasa/Boa Vista:

| Campo | Tipo | Descrição |
|---|---|---|
| `injunction` | boolean | Indica liminar sobre os protestos. |
| `protestsQuantity` | number | Quantidade de protestos. |
| `protestsTotalValue` | string | Valor total, **já formatado** (ex.: `"R$ 12.400,00"`). |
| `lastProtestDate` | string | Data do protesto mais recente (crua). |
| `formattedLastProtestDate` | string | A mesma data formatada para exibição. |
| `protestsByRegion` | object[] | Agregado por UF: `{ name, value }`, onde `value` é a contagem. |
| `protestsTable` | object[] | Lista dos protestos. Campos abaixo. |

### `protestsTable[]`

| Campo | Tipo | Descrição |
|---|---|---|
| `name` | string | Nome do titular do documento analisado. |
| `registry` | string | Cartório: nome ou número do ofício. |
| `date` | date | Data da ocorrência (crua, para cálculo). |
| `formattedDate` | string | A mesma data formatada. |
| `uf` | string | Cidade e UF concatenadas, no formato `"CIDADE/UF"`. |
| `value` | number | Valor do protesto (cru). |
| `formattedValue` | string | O mesmo valor formatado em reais. |

<Warning>
  O conjunto de campos **depende do provedor** que respondeu. Políticas que usam outra fonte de protestos devolvem outra chave em `values`, com campos próprios. Ver [Estrutura do Relatório](/data/estrutura-relatorio#onde-ficam-os-dados-sectiondetails-values).
</Warning>
