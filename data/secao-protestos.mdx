A seção `PROTESTS` traz os protestos em cartório registrados para o documento. A **fonte** dos dados é configurável na política, e isso afeta a abrangência geográfica do retorno.

Disponível no relatório **COMPLETO** e **COMPLETO+**.

## Como os dados são coletados

Os dados de protestos podem vir de duas fontes, escolhidas na política de crédito:

1. **Bureau selecionado na análise (padrão):** por padrão, os protestos são consultados no **mesmo bureau** escolhido para a análise (Serasa, Boa Vista, ProScore etc.). A abrangência depende do **acordo comercial de cada bureau com os cartórios**: nem todo bureau tem convênio de alcance nacional, então a cobertura pode ser **parcial** (regional ou limitada a um conjunto de cartórios).
2. **Protestos Cenprot (fonte adicional, opcional):** para garantir **cobertura nacional**, basta selecionar **Protestos Cenprot** como fonte adicional de dados na edição da política de crédito. O Cenprot consolida os protestos de cartórios de todo o Brasil. Essa opção tem **custo adicional** por consulta.

<Note>
A estrutura de campos (`count`, `totalAmount`, `protests[]` etc.) é a mesma independentemente da fonte. O que muda é a **abrangência**: o bureau cobre o que o convênio dele alcança; o Cenprot garante alcance nacional. Quando o Cenprot está habilitado, são os dados dele que populam a seção e são avaliados pelas regras.
</Note>

## Campos do `details`

### Totalizadores

| Campo | Tipo | Descrição |
|-------|------|-----------|
| `count` | number | Quantidade total de protestos |
| `totalAmount` | number | Valor total protestado (R$) |
| `lastOccurrenceDate` | string | Data do protesto mais recente |
| `firstOccurrenceDate` | string | Data do protesto mais antigo |
| `calculatedRevenuePercentage` | number | % do faturamento comprometido em protestos |

### Lista de protestos (`protests[]`)

| Campo | Tipo | Descrição |
|-------|------|-----------|
| `id` | string | ID do protesto |
| `amount` | number | Valor do protesto (R$) |
| `protestDate` | string | Data do protesto |
| `creditor` | string | Credor |
| `notary` | string | Cartório responsável |
| `city` | string | Cidade |
| `state` | string | Estado (UF) |
| `instrumentType` | string | Tipo de instrumento: `DUPLICATA`, `CHEQUE`, `CCB`, `NOTA_PROMISSORIA`, etc. |

## Regras sugeridas para protestos

| Objetivo | Regra | Critério |
|----------|-------|----------|
| Sem protestos | `NOTARIES_COUNT` | = 0 → APPROVED |
| Tolerância mínima | `NOTARIES_COUNT` | BETWEEN 1–2 → ALERT |
| Negar acima de X | `NOTARIES_AMOUNT` | > R$ 50.000 → DENIED |
| Protestos recentes | `NOTARIES_LAST_DAYS` | = 0 nos últimos 90 dias → APPROVED |
| Proporcional | `NOTARIES_NOT_CALCULATED_REVENUE` | < 5% → APPROVED |
