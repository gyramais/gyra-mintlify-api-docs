<Info>
  **Resumo:** esta é a lista completa das **153 regras** que a GYRA+ disponibiliza para montar as **Condições** de uma política. São as mesmas que aparecem no editor, agrupadas pela mesma categoria. Cada regra tem um identificador estável e vale para PF, PJ ou ambos.
</Info>

## Como ler

Uma condição é montada escolhendo uma **regra** do catálogo, um **operador** e um **valor de comparação**. Algumas regras pedem parâmetros extras (por exemplo, o tipo de vara em `LAWSUITS_COUNT_BY_COURT_TYPE`).

<Warning>
  **Regra não é campo de resposta.** O identificador aqui (`SCORE`, `COMPANY_SITUATION`) é o que você seleciona ao montar a política. Ele **não** é o caminho do dado no JSON do relatório, e não existe sintaxe de campo aninhado do tipo `objeto.propriedade` para escrever regra. Para o formato dos dados retornados, veja o [Dicionário de Dados](/data/estrutura-relatorio).
</Warning>

<Note>
  Disponibilidade depende das [Fontes de dados](/concepts/politica-de-credito#fontes-de-dados) ativadas na política e do nível do Relatório base. Uma regra de SCR só aparece se o SCR estiver ligado. Além destas, a sua organização pode criar **[Minhas variáveis](/concepts/politica-de-credito)** e regras próprias sobre bases externas.
</Note>
