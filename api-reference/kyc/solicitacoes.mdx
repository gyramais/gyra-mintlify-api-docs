<Info>
  **Resumo:** uma solicitação nasce de um modelo, aponta para um cadastro e vai para um ou mais destinatários. Prefixo `/v1/collections`. Toda rota aceita `can-generate-report` ou `can-use-registry-api`.
</Info>

## Rotas

| Método | Caminho | O que faz |
| --- | --- | --- |
| `POST` | `/collections` | Cria a solicitação a partir de um modelo |
| `GET` | `/collections` | Lista as solicitações da organização |
| `GET` | `/collections/{id}` | Detalhe com itens, destinatários e trilha |
| `POST` | `/collections/{id}/send` | Dispara o envio (ou reenvio) e devolve os links |
| `POST` | `/collections/{id}/cancel` | Cancela |
| `POST` | `/collections/{id}/recipients/{recipientId}/reissue` | Reemite o link do destinatário |
| `POST` | `/collections/{id}/items/{itemId}/review` | Decisão do operador sobre um item |
| `POST` | `/collections/{id}/items/{itemId}/waive` | Dispensa um item |
| `POST` | `/collections/{id}/items/{itemId}/signatories` | Inclui uma parte num documento conjunto |
| `POST` | `/collections/{id}/signatories/{signatoryId}/remove` | Remove uma parte que ainda não assinou |
| `POST` | `/collections/{id}/items/{itemId}/identity-media` | Abre as imagens da verificação de identidade |
| `POST` | `/collections/notification-preview` | A mensagem que a solicitação vai mandar, sem mandar |
| `GET` | `/collections/contact-suggestion/{document}` | Contatos que este documento já usou |
| `POST` | `/collections/signatory-suggestion` | Sugere quem assina, a partir do documento societário |

## Criar

`POST /v1/collections`

```json
{
  "template": "onboarding-pj",
  "document": "12.345.678/0001-90",
  "recipients": [
    {
      "name": "Ana Souza",
      "document": "12345678909",
      "email": "ana@exemplo.com.br",
      "phone": "+5551999998888",
      "role": "Sócia administradora · 60%",
      "registryPersonId": "6612a7f30000000000000021"
    }
  ],
  "dueInDays": 10,
  "channel": "BOTH",
  "responseMode": "REVIEW",
  "message": "Precisamos destes documentos para liberar seu limite.",
  "callbackUrl": "https://api.suaempresa.com/gyra/kyc",
  "forceItemKeys": ["comprovante-de-residencia"],
  "send": true
}
```

| Campo | Tipo | Obrigatório | Nota |
| --- | --- | --- | --- |
| `template` | string | sim | **Slug** do modelo, não o id. É o endereço estável entre versões |
| `document` | string | sim* | CNPJ/CPF do cadastro. O cadastro é resolvido ou criado |
| `registryId` | string | sim* | Alternativa a `document`, quando você já está dentro do dossiê |
| `recipients[]` | lista | sim | De 1 a 30 destinatários |
| `parties[]` | lista | não | Partes de documento conjunto **sem contato ainda**. Máximo 50 |
| `dueInDays` | inteiro | não | Padrão 7, máximo 180 |
| `message` | string | não | Recado do operador, até 1000 caracteres |
| `responseMode` | enum | não | `AUTOMATIC` ou `REVIEW`; sobrescreve o modelo |
| `channel` | enum | não | `EMAIL`, `WHATSAPP`, `BOTH` ou `NONE`; sobrescreve o modelo |
| `callbackUrl` | url `https` | não | Webhook desta solicitação, com o mesmo HMAC do cadastro |
| `forceItemKeys` | lista | não | Chaves de item a pedir mesmo que o cadastro já as tenha. Máximo 50 |
| `draft` / `send` | booleano | não | `draft: true` (ou `send: false`) cria sem enviar |

<Note>
  `document` **ou** `registryId`: um dos dois é obrigatório.
</Note>

### Destinatário

| Campo | Obrigatório | Nota |
| --- | --- | --- |
| `name` | sim | |
| `document` | não | CPF/CNPJ do destinatário |
| `email` | condicional | Obrigatório junto com `phone` quando o canal não é `NONE` |
| `phone` | condicional | E.164 (`+5551900001234`) |
| `role` | não | Como aparece na tela, por exemplo `Sócio administrador · 47%` |
| `registryPersonId` | não | Liga o destinatário a uma pessoa da árvore societária |
| `signatureRole` | não | `SIGNATARIO` (padrão), `TESTEMUNHA` ou `INTERVENIENTE` |
| `signatureRequired` | não | Se a assinatura desta parte é obrigatória para o documento fechar |

<Tip>
  Com `channel: "NONE"` a plataforma **não avisa ninguém**: a solicitação é criada, os links são gerados e voltam na resposta (`publicUrl` quando há um destinatário, `links[]` sempre), e quem entrega é você. O lembrete também não sai. É o caminho para quem já fala com o cliente pelo canal próprio.
</Tip>

## Listar

`GET /v1/collections`

| Query | Nota |
| --- | --- |
| `status` | Repetível: `DRAFT`, `SENT`, `IN_PROGRESS`, `COMPLETED`, `EXPIRED`, `CANCELED` |
| `registryId` | Filtra por cadastro |
| `document` | Filtra pelo CNPJ/CPF do cadastro |
| `templateId` | Filtra por modelo |
| `search` | Casa por nome ou documento |
| `from` / `to` | Período de criação, ISO 8601 |
| `skip` / `take` | Paginação |

## Detalhe

`GET /v1/collections/{id}`

Traz a solicitação, seus itens (com status e parecer de cada um), os destinatários (com estado de entrega) e a trilha.

## Enviar e reenviar

`POST /v1/collections/{id}/send`

```json
{ "message": "Reforçando o pedido, o prazo vence sexta." }
```

Dispara o envio pelos canais do destinatário e devolve os links por destinatário. Serve tanto para o primeiro envio de um rascunho quanto para reenviar.

## Reemitir link

`POST /v1/collections/{id}/recipients/{recipientId}/reissue`

Gera um link novo para aquele destinatário. Limite de 3 reemissões.

## Revisar um item

`POST /v1/collections/{id}/items/{itemId}/review`

```json
{
  "decision": "RESEND_REQUESTED",
  "comment": "O comprovante está no nome de outra pessoa. Envie um no seu nome."
}
```

| `decision` | O que faz | `comment` |
| --- | --- | --- |
| `APPROVED` | Aprova o item | opcional |
| `RESEND_REQUESTED` | Pede de novo ao destinatário | **obrigatório** |
| `WAIVED` | Dispensa | opcional |

## Dispensar

`POST /v1/collections/{id}/items/{itemId}/waive`

```json
{ "comment": "Cliente enviou por outro canal, já anexado ao dossiê." }
```

## Cancelar

`POST /v1/collections/{id}/cancel`

```json
{ "reason": "Operação desistida pelo cliente." }
```

## Assinatura conjunta

`POST /v1/collections/{id}/items/{itemId}/signatories` (responde `201`)

```json
{
  "name": "Bruno Lima",
  "document": "98765432100",
  "email": "bruno@exemplo.com.br",
  "signatureRole": "SIGNATARIO",
  "signatureRequired": true
}
```

`POST /v1/collections/{id}/signatories/{signatoryId}/remove` remove uma parte que **ainda não assinou**.

```json
{ "reason": "Saiu do quadro societário na última alteração." }
```

## Imagens da verificação de identidade

`POST /v1/collections/{id}/items/{itemId}/identity-media`

Abre selfie e documento da verificação. É uma **ação explícita** de propósito: são dado pessoal sensível, e a trilha registra quem viu e quando.

## Pré-visualizar a mensagem

`POST /v1/collections/notification-preview`

Devolve o e-mail e a mensagem de WhatsApp exatos que sairiam, com a marca aplicada, sem enviar nada.

## Sugestões

`GET /v1/collections/contact-suggestion/{document}` devolve os e-mails e telefones que aquele CNPJ/CPF já usou em solicitações anteriores.

`POST /v1/collections/signatory-suggestion` devolve quem assina pela empresa, deduzido do documento societário vigente do cadastro: nome, documento, papel e o regime de assinatura já lido (`ISOLADA`, `CONJUNTA`, `MISTA` ou `INDETERMINADO`).
