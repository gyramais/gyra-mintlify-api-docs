<Info>
  **Resumo:** você manda um arquivo e não diz o que ele é. A plataforma identifica o tipo e devolve, em `extraction`, os campos **daquele tipo**. Esta página lista todos, para todos os tipos, com o rótulo em português que a plataforma usa nas telas.
</Info>

## A convenção de todo campo

Todo campo folha volta como uma **tripla**:

```json
{
  "value": "12345678000190",
  "confidence": 0.97,
  "page": 1
}
```

| Chave | O que é |
| --- | --- |
| `value` | O valor lido, no tipo do campo, ou `null` |
| `confidence` | Confiança de 0 a 1 |
| `page` | Página em que o dado foi lido, ou `null` |

Regras que valem para todos os tipos:

- **Campo ausente no documento** vem com `value: null` e `confidence: 0`. Nada é inventado.
- **Datas** vêm como texto no formato `YYYY-MM-DD`; data e hora, em ISO 8601.
- **Valores monetários** vêm como número puro, na moeda declarada em `currency` ou `capitalCurrency` (moeda antiga não é convertida).
- **Listas** são arrays de objetos cujos campos também são triplas.
- Um campo pode trazer `discardReason` quando uma checagem determinística o anulou de propósito. O valor sai nulo, e o motivo sobrevive para a auditoria.

<Tip>
  Trate o schema como **aditivo**. Campo novo pode aparecer numa versão futura sem quebrar contrato, e o seu parser deve ignorar o que não conhece.
</Tip>

## Campos críticos

Cada tipo tem um punhado de campos **críticos**: são eles que puxam o parecer para baixo quando vêm com confiança fraca, e é sobre eles que rodam as verificações de titularidade (`EXPECTED_DOCUMENT_MATCH`, `EXPECTED_NAME_MATCH`, `DOC_CHECKSUM`). Estão listados em cada tipo abaixo.

O **documento principal** e o **nome principal** de cada tipo dizem qual campo representa a entidade do cadastro: no contrato social é `cnpj` e `companyName`; na procuração é `grantorDocument` e `grantorName`; no comprovante de residência é `holderDocument` e `holderName`.

## Blocos compartilhados

Quatro blocos aparecem em vários tipos com exatamente a mesma forma. Estão documentados aqui uma vez, e referenciados nas tabelas de cada tipo.

### Bloco Certificação

`certification`: o que dá fé ao documento. Está em **todos** os tipos.

| Campo | Tipo | Rótulo |
| --- | --- | --- |
| `certification.certificationKind` | texto, um de: `SEM_CERTIFICACAO`, `ASSINATURA_MANUSCRITA`, `ASSINATURA_CONTADOR`, `ASSINATURA_ELETRONICA`, `FIRMA_RECONHECIDA`, `CERTIFICADO_DIGITAL`, `ORGAO_EMISSOR` | Espécie de certificação |
| `certification.certificationDetail` | texto | Como aparece no documento |
| `certification.accountantName` | texto | Contador responsável |
| `certification.accountantCrc` | texto | CRC do contador |
| `certification.notaryOffice` | texto | Cartório |
| `certification.notaryDate` | data | Data do reconhecimento de firma |
| `certification.verificationCode` | texto | Código de autenticidade |
| `certification.verificationUrl` | texto | Endereço de conferência |

### Bloco Marcadores estruturais

`structuralMarkers`: os títulos e seções canônicos **encontrados** no documento. Insumo da checagem de anatomia, não dado do documento. Está em todos os tipos.

| Campo | Tipo | Rótulo |
| --- | --- | --- |
| `structuralMarkers[].title` | texto | Título encontrado, copiado como impresso |
| `structuralMarkers[].excerpt` | texto | Linha onde o título aparece |

### Bloco Marcadores de integridade

`documentMarkers`: marcas de integridade do arquivo. Insumo da heurística de página faltante. Aparece nos tipos societários e no requerimento de empresário.

| Campo | Tipo | Rótulo |
| --- | --- | --- |
| `documentMarkers.declaredTotalPages` | inteiro | Total de páginas que o documento declara |
| `documentMarkers.citedSheetMax` | inteiro | Maior folha citada ("fls. 47") |
| `documentMarkers.clauseNumbers` | texto | Números das cláusulas que aparecem, separados por vírgula |
| `documentMarkers.hasSignatureBlock` | sim/não | Há bloco de assinaturas/fecho |

### Bloco Poderes de representação

`representation`: a cláusula de administração lida de forma estruturada. Aparece em contrato social, alteração contratual, estatuto, ata de assembleia e certidão da Junta.

| Campo | Tipo | Rótulo |
| --- | --- | --- |
| `representation.regime` | texto, um de: `ISOLADA`, `CONJUNTA`, `MISTA`, `INDETERMINADO` | Regime de assinatura |
| `representation.signersRequired` | inteiro | Assinaturas exigidas na regra geral |
| `representation.thresholds[].actType` | texto | Ato ou grupo de atos da faixa |
| `representation.thresholds[].amountFrom` | número | A partir de |
| `representation.thresholds[].amountTo` | número | Até |
| `representation.thresholds[].currency` | texto | Moeda |
| `representation.thresholds[].signersRequired` | inteiro | Quantos assinam nesta faixa |
| `representation.thresholds[].requiresPartnerApproval` | sim/não | Exige aprovação dos sócios |
| `representation.thresholds[].approvalQuorumPercent` | número | Quórum de aprovação (%) |
| `representation.thresholds[].approvalQuorumText` | texto | Quórum como está escrito |
| `representation.prohibitions[].type` | texto, um de: `AVAL`, `FIANCA`, `HIPOTECA`, `ALIENACAO_IMOVEL`, `EMPRESTIMO_A_SOCIO`, `DOACAO`, `OUTROS` | Espécie da vedação |
| `representation.prohibitions[].scope` | texto | A quem a vedação se aplica |
| `representation.prohibitions[].absolute` | sim/não | Vedação absoluta |
| `representation.prohibitions[].requiresApproval` | sim/não | Exige aprovação |
| `representation.prohibitions[].approvalQuorumPercent` | número | Quórum de aprovação (%) |
| `representation.prohibitions[].approvalQuorumText` | texto | Quórum como está escrito |
| `representation.prohibitions[].excerpt` | texto | Trecho literal da vedação |
| `representation.mandate.termYears` | número | Prazo (anos) |
| `representation.mandate.startDate` | data | Início |
| `representation.mandate.endDate` | data | Término |
| `representation.mandate.indefinite` | sim/não | Prazo indeterminado |
| `representation.mandate.reconductionRule` | texto | Recondução |
| `representation.clauseNumber` | texto | Cláusula |
| `representation.clauseExcerpt` | texto | Trecho literal da cláusula |

<Note>
  Um mesmo trecho do contrato vai em **um** dos dois: ato que só exige aprovação ou quórum é alçada (`thresholds`); ato vedado é vedação (`prohibitions`). Nunca nos dois.
</Note>
