<Info>
  **Resumo:** uma chamada `multipart`, um arquivo, e o resultado volta na resposta. Se o pipeline terminar dentro da janela que você pediu, a resposta é `200` com o resultado completo. Se não terminar, é `202` com uma `statusUrl` para continuar por polling.
</Info>

## A rota

`POST /v1/registry/validate-document`

`Content-Type: multipart/form-data`

| Campo | Tipo | Obrigatório | Nota |
| --- | --- | --- | --- |
| `file` | binário | sim | PDF, JPG ou PNG, **até 15 MB** |
| `expectedDocument` | string | sim | CNPJ ou CPF da jornada, com ou sem máscara |
| `expectedName` | string | não | Razão social ou nome da jornada (alimenta `EXPECTED_NAME_MATCH`) |
| `waitSeconds` | inteiro | não | Espera máxima. Entre 5 e 55, padrão 45 |
| `typeHint` | enum | não | **Afirma** o tipo: pula a classificação |
| `expectedType` | enum | não | **Pede** um tipo: a classificação roda e é confrontada |

<Warning>
  O teto aqui é **15 MB**, menor que o dos 50 MB do caminho assíncrono. Arquivo maior usa [presign + confirm](/api-reference/kyc/documentos).
</Warning>

## Exemplo

<CodeGroup>

```bash cURL
curl --location 'https://gyra-core.gyramais.com.br/v1/registry/validate-document' \
  --header 'Authorization: Bearer <token>' \
  --form 'file=@"/caminho/comprovante.pdf"' \
  --form 'expectedDocument="529.982.247-25"' \
  --form 'expectedName="Ana Souza"' \
  --form 'expectedType="COMPROVANTE_RESIDENCIA"' \
  --form 'waitSeconds="45"'
```

```javascript Node
const form = new FormData();
form.append("file", fs.createReadStream("comprovante.pdf"));
form.append("expectedDocument", "52998224725");
form.append("expectedName", "Ana Souza");
form.append("expectedType", "COMPROVANTE_RESIDENCIA");

const res = await fetch(
  "https://gyra-core.gyramais.com.br/v1/registry/validate-document",
  { method: "POST", headers: { Authorization: `Bearer ${token}` }, body: form },
);

if (res.status === 202) {
  const { documentId, statusUrl } = await res.json();
  // continue por polling em statusUrl
} else {
  const resultado = await res.json();
}
```

```python Python
import requests

with open("comprovante.pdf", "rb") as arquivo:
    resposta = requests.post(
        "https://gyra-core.gyramais.com.br/v1/registry/validate-document",
        headers={"Authorization": f"Bearer {token}"},
        files={"file": arquivo},

            "expectedType": "COMPROVANTE_RESIDENCIA",
        },
```

## As duas respostas

### `200`: terminou dentro da janela

O corpo é o mesmo do [resultado completo do documento](/api-reference/kyc/documentos#4-ler-o-resultado): classificação, extração, verificações e parecer.

### `202`: ainda processando

```json
{
  "documentId": "6612a7f30000000000000031",
  "statusUrl": "https://gyra-core.gyramais.com.br/v1/registry/documents/6612a7f30000000000000031/status"
}
```

Continue por `GET` na `statusUrl` até o status ser terminal (`VALIDATED`, `FAILED`, `OUT_OF_SCOPE`, `MANUAL_REVIEW`, `REJECTED_QUALITY`), ou assine os [webhooks](/api-reference/kyc/eventos-de-webhook) e pare de fazer polling.

<Tip>
  Documento pequeno e simples (uma certidão, um comprovante de residência) costuma fechar dentro da janela. Documento societário longo, digitalizado ou com várias peças costuma passar de 55 segundos: trate o `202` como o caminho normal, não como exceção.
</Tip>

## Entrada única, saída que depende do documento

Você não diz que documento está mandando. A plataforma identifica entre os [25 tipos](/kyc/tipos-de-documento), e o objeto `extraction` da resposta tem os campos **daquele tipo**: um contrato social devolve sócios, capital e cláusula de administração; um comprovante de residência devolve titular, concessionária, endereço e mês de referência.

O mapa completo, campo a campo, está em [Formatos de retorno por documento](/api-reference/kyc/formatos-de-retorno).

Para conferir se veio o documento certo, mande `expectedType`. Ele não força nada: a classificação roda normalmente e o tipo lido é confrontado, o que pega o arquivo legítimo enviado no lugar errado.

## Onde o documento fica

O arquivo validado por esta rota é arquivado no cadastro de `expectedDocument`, criando o cadastro se ele ainda não existia. Ou seja: mesmo usando só o caminho síncrono, você acumula o dossiê.
