### Quando usar

Quando você já tem o id e quer o dossiê completo.

### Só o detalhe traz estes dois

`completenessSlots` abre a completude por exigência, dizendo qual documento cobre cada uma. `signingAuthority` traz quem assina pela empresa, já achatado, lido do documento societário vigente.

Na listagem eles não vêm: seria uma consulta por linha.
