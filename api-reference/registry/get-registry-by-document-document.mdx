### Quando usar

Antes de pedir documento ao cliente: responde "o que já temos deste CNPJ?" sem você guardar o id do cadastro.

### Dois campos respondem quase tudo

`kycStatus` diz se libera (`UP_TO_DATE`) ou se pede ação (`ATTENTION`, `EXPIRED`). `completenessSlots` diz exatamente o que falta.
