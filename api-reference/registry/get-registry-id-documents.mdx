### Quando usar

Para saber o que o dossiê já tem antes de pedir de novo.

### O que some por padrão

Nada é sobrescrito: a alteração contratual nova não apaga a antiga, vira a versão vigente. Por padrão some só a versão **aprovada** que já foi substituída por uma vigente do mesmo tipo. Documento reprovado, inconclusivo ou ainda em análise aparece sempre. Com `includeHistory`, vem tudo; com `type`, só um tipo.

A lista vem em `documents`, e cada documento traz `verdict`: o veredito que vale hoje, já com a decisão do operador quando houver.
