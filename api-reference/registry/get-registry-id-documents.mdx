### Quando usar

Para saber o que o dossiê já tem antes de pedir de novo.

### Versão vigente por padrão

Nada é sobrescrito: a alteração contratual nova não apaga a antiga, vira a versão vigente. Por padrão a listagem traz só a vigente de cada tipo; com `includeHistory`, traz todas.
