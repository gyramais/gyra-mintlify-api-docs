### Quando usar

Quando você precisa do detalhe: os campos lidos, cada verificação com evidência, e o parecer.

### O que olhar primeiro

| Campo | Para quê |
| --- | --- |
| `assessment.effectiveVerdict` | O veredito que **vale hoje**. Não use `verdict` |
| `validation.checks[]` | Cada verificação com `PASS`, `WARN`, `FAIL` ou `SKIP`, mensagem e evidência |
| `statusReason` | Por que parou, quando não houve falha técnica |
| `stages` | O que rodou nesta tentativa e o que veio reaproveitado |

O objeto `extraction` tem os campos do tipo identificado. Ver [Formatos de retorno](/api-reference/onboarding/formatos-de-retorno).
