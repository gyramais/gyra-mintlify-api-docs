### Quando usar

Quando o cliente diz que "parou de receber": aqui aparece se a assinatura foi desligada e por quê.

Assinatura que acumula **20 falhas seguidas** é desligada sozinha. `consecutiveFailures`, `lastDeliveryStatus` e `lastDeliveryError` contam a história.

O segredo não volta aqui: só uma dica com os últimos caracteres.
