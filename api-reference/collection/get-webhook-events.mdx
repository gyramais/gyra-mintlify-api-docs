### Quando usar

Para montar a sua tela de configuração sem fixar a lista de eventos no código.

Evento novo aparece aqui no mesmo deploy em que passa a existir. A lista completa, com payload, está em [Eventos de webhook](/api-reference/onboarding/eventos-de-webhook).

</Note>
