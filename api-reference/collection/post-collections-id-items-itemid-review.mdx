### Quando usar

Modo de resposta com revisão: a IA avaliou e a decisão é sua.

### As três saídas

| `decision` | O que faz | `comment` |
| --- | --- | --- |
| `APPROVED` | O item fecha | opcional |
| `RESEND_REQUESTED` | O destinatário recebe o pedido outra vez | **obrigatório** |
| `WAIVED` | O item sai do pedido | opcional |

A resposta é a solicitação inteira, já com o item no status novo. Item que não está aguardando decisão responde `409`, e cada item aceita até 3 pedidos de reenvio: depois disso, aprove ou dispense.

<Warning>
  Em `RESEND_REQUESTED`, o `comment` é o texto que **o cliente lê**. Escreva o que precisa ser corrigido, não o código da verificação.
</Warning>
