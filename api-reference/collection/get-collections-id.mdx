### Quando usar

Para acompanhar item a item e ver o estado de entrega de cada destinatário.

### O estado que mais importa

`recipients[].status` em **`FAILED`** quer dizer que a mensagem **não chegou**. É o caso de ligar para o cliente, e é por isso que vale assinar `collection.message.failed`.

`items[].files[]` traz o parecer de cada arquivo, quando o item aceita mais de um.
