### Quando usar

Para responder "quem está devendo documento?": filtre por `SENT` e `IN_PROGRESS` e olhe o prazo.

`itemsAwaitingOperator` diz quantos itens esperam uma decisão sua, que é a fila que trava a solicitação do lado de dentro.

</Note>
