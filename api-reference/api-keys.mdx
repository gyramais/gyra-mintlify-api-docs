Para usar a API da GYRA+ você precisa de credenciais vinculadas à sua organização: `gyra-client-id` e `gyra-client-secret`.

<Info>
  **Você mesmo gera as credenciais**, no toolbox, em **Configurações, API & MCP**. Não é preciso pedir ao suporte.
</Info>

### 1. Gerar a credencial

<Steps>
  <Step title="Abra Configurações, API & MCP">
    Criar e revogar credenciais exige a permissão de **gerenciar configurações** da organização.
  </Step>
  <Step title="Crie a credencial">
    Na seção **Credenciais de API**, clique em criar e dê um nome reconhecível (`backend-producao`, `n8n-homologacao`).
  </Step>
  <Step title="Copie o par">
    O `clientId` e o `clientSecret` aparecem na tela. O painel só fecha depois que você confirma que copiou.
  </Step>
</Steps>

<Warning>
  O `clientSecret` é mostrado **uma única vez**. A plataforma guarda apenas o hash dele e não há rota que o devolva. Se perder, crie outra credencial e revogue a anterior.
</Warning>

Crie uma credencial por integração e por ambiente: assim dá para revogar a de homologação sem derrubar a produção. A listagem mostra o `clientId` e a data de criação de cada uma, com a ação de revogar.

### 2. Autenticação inicial

Troque o par por um token de acesso em `POST /auth/authenticate`, com os headers:

| Header               | Tipo     | Obrigatório | Descrição                          |
|----------------------|----------|-------------|------------------------------------|
| `gyra-client-id`     | `string` | sim         | Client ID da credencial            |
| `gyra-client-secret` | `string` | sim         | Chave secreta gerada no painel     |

```bash
curl -X POST https://gyra-core.gyramais.com.br/auth/authenticate \
  -H "gyra-client-id: seu-client-id" \
  -H "gyra-client-secret: seu-client-secret"
```

O token vale 24 horas. Renove antes de expirar.

### 3. Requisições autenticadas

Inclua o token em toda chamada:

| Header         | Tipo     | Obrigatório | Descrição                         |
|----------------|----------|-------------|-----------------------------------|
| `Authorization`| `string` | sim         | Token no formato `Bearer {token}` |

```
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6...
```

<Note>
  O **MCP da GYRA+** não usa estas credenciais: a autenticação dele é o seu próprio login da plataforma. Ver [Instalação do MCP](/mcp/instalacao).
</Note>
