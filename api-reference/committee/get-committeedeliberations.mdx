### Quando usar

Use este endpoint quando precisa da **deliberação completa e auditável**: o voto individual de cada um dos sete agentes, os alertas que cada um levantou, o registro de divergência, a versão de prompt usada e a telemetria (modelos, tokens, custo e duração).

É o endpoint de **auditoria e compliance**. Para o dia a dia da integração (decisão + pareceres), [`GET /report/{id}/insights`](/api-reference/report/get-reportinsights) é mais leve e costuma bastar.

<Note>
  Retorna sempre a deliberação **mais recente** do relatório. Reconvocações (`trigger: "RERUN"`) geram uma nova deliberação, e é ela que passa a ser devolvida.
</Note>

### Autenticação

Bearer JWT no header `Authorization`. A busca é restrita à organização do token.

### Parâmetros

| Nome | Local | Tipo | Obrigatório | Descrição |
|---|---|---|---|---|
| `reportId` | `path` | `string` | `sim` | ID do relatório que foi a comitê. |

### Resposta

| Campo | Descrição |
|---|---|
| `id` | ID da deliberação. |
| `reportId` | Relatório deliberado. |
| `policyId` / `policyVersion` | Política e versão vigentes na deliberação. |
| `trigger` | `AUTO_SUGGEST`, `AUTO_DECIDE`, `MANUAL` ou `RERUN`. |
| `status` | `RUNNING`, `DONE` ou `ERROR`. |
| `agentOpinions[]` | Um objeto por agente: `agent`, `agentLabel`, `score` (0 a 10), `resumo`, `parecer`, `redFlags[]`, `positiveFactors[]`, `confidence`, `infoGaps[]`, `recommendation`, `model`, `costUsd` e `sectionsSeen[]`. |
| `synthesis` | Saída do Presidente: `decision`, `resumo`, `reasoning`, `proximaAcao`, `conditions[]`, `dissentLog[]`, `monitoringItems[]`, `infoGapsBeforeDecision[]`, `limitReview`, `confidence`, `alcadaLevel`. |
| `finalRecommendation` | `APPROVED`, `REJECTED`, `REQUIRES_ALCADA` ou `NEEDS_INFO`. |
| `confidence` | Confiança agregada da deliberação (0 a 1). |
| `promptVersion` | Versão do prompt-base GYRA+ usada. |
| `customPrompts` | `true` quando a organização tinha instruções adicionais ativas. |
| `promptVersionsByAgent` | Versão de prompt base e da organização por agente. Permite rastrear a relação entre uma mudança de instrução e a decisão. |
| `totalInputTokens` / `totalOutputTokens` / `totalCostUsd` | Telemetria de consumo da deliberação. |
| `webSearchRequests` | Buscas na web feitas pelo agente Cadastral. |
| `durationMs` | Duração total da deliberação. |
| `modelVersions` | Modelos usados por etapa. |
| `error` | Preenchido quando `status` é `ERROR`. |
