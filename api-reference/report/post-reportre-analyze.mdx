### Quando usar

Use esta rota para trocar a decisão de um relatório que já foi decidido, por exemplo de aprovado para reprovado depois de uma informação nova. A decisão nova vira o `status` do relatório, e a anterior fica em `previousStatus`, `previousAnalystId`, `previousAnalystName` e `previousAnalyzedAt`.

<Info>
  A chamada não reprocessa as fontes e não altera a justificativa já registrada: o campo `commentary` do corpo é ignorado nesta rota.
</Info>

Os webhooks `REPORT_STATUS` da organização recebem o evento.

### Autenticação

Bearer JWT no header `Authorization`. Só refaz a análise quem está na lista de quem pode editar relatórios, configurada na política do relatório (por usuário ou por papel). Fora da lista, a resposta é `401`.

<Warning>
  Na prática, a reanálise é feita por um usuário com essa alçada, pela tela do Toolbox. Uma credencial de API fora da lista recebe `401` *"Você não tem permissão para reanalisar esse relatório."*
</Warning>

### Corpo da requisição

| Campo | Tipo | Obrigatório | Descrição |
|---|---|---|---|
| `id` | `string` | sim | ID do relatório. |
| `approved` | `boolean` | sim | Nova decisão: `true` aprova, `false` reprova. |

```json
{
  "id": "6612a7f3a19b467000000000",
  "approved": false
}
```

<RequestExample>

```bash cURL
curl --request POST 'https://gyra-core.gyramais.com.br/report/re-analyze' \
  --header 'Authorization: Bearer SEU_TOKEN' \
  --header 'Content-Type: application/json' \
  --data '{
    "id": "6612a7f3a19b467000000000",
    "approved": false
  }'
```

```javascript JavaScript
const resposta = await fetch("https://gyra-core.gyramais.com.br/report/re-analyze", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${token}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({ id: "6612a7f3a19b467000000000", approved: false }),
});
const relatorio = await resposta.json();
```

```python Python
import requests

resposta = requests.post(
    "https://gyra-core.gyramais.com.br/report/re-analyze",
    headers={"Authorization": f"Bearer {token}"},
    json={"id": "6612a7f3a19b467000000000", "approved": False},
)
relatorio = resposta.json()
```

</RequestExample>

### Erros

| Código | Mensagem | Causa |
|---|---|---|
| `400` | `"id should not be empty,id must be a string,approved should not be empty,approved must be a boolean value"` | Corpo sem `id` ou sem `approved`. |
| `401` | `"Você não tem permissão para reanalisar esse relatório."` | O usuário não está na lista de quem pode editar relatórios da política. |
