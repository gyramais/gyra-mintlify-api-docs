### Quando usar

Use esta rota para registrar a decisão humana sobre um relatório: aprovado ou reprovado, com uma justificativa opcional. É a mesma ação dos botões de decisão do Toolbox. O status do relatório passa de `PENDING` para `APPROVED` ou `REJECTED`.

<Info>
  A chamada não reprocessa as fontes: só grava a decisão. Ela vale uma vez por relatório. Para trocar uma decisão já registrada, use [`POST /report/re-analyze`](/api-reference/report/post-reportre-analyze).
</Info>

Quando a decisão é gravada, os webhooks `REPORT_STATUS` da organização recebem o evento.

### Autenticação

Bearer JWT no header `Authorization`. Com credencial de API, a decisão fica assinada como **Usuário API**.

### Corpo da requisição

| Campo | Tipo | Obrigatório | Descrição |
|---|---|---|---|
| `id` | `string` | sim | ID do relatório. |
| `approved` | `boolean` | sim | `true` aprova, `false` reprova. |
| `commentary` | `string` | não | Justificativa da decisão. |

```json
{
  "id": "6612a7f3a19b467000000000",
  "approved": true,
  "commentary": "Aprovado após análise manual."
}
```

<RequestExample>

```bash cURL
curl --request POST 'https://gyra-core.gyramais.com.br/report/analyze' \
  --header 'Authorization: Bearer SEU_TOKEN' \
  --header 'Content-Type: application/json' \
  --data '{
    "id": "6612a7f3a19b467000000000",
    "approved": true,
    "commentary": "Aprovado após análise manual."
  }'
```

```javascript JavaScript
const resposta = await fetch("https://gyra-core.gyramais.com.br/report/analyze", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${token}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    id: "6612a7f3a19b467000000000",
    approved: true,
    commentary: "Aprovado após análise manual.",
  }),
});
const relatorio = await resposta.json();
```

```python Python
import requests

resposta = requests.post(
    "https://gyra-core.gyramais.com.br/report/analyze",
    headers={"Authorization": f"Bearer {token}"},
    json={
        "id": "6612a7f3a19b467000000000",
        "approved": True,
        "commentary": "Aprovado após análise manual.",
    },
)
relatorio = resposta.json()
```

### Erros

| Código | Mensagem | Causa |
|---|---|---|
| `400` | `"id should not be empty,id must be a string,approved should not be empty,approved must be a boolean value"` | Corpo sem `id` ou sem `approved`. |
| `400` | `"O relatório já foi analisado."` | O relatório já tem decisão. Use `POST /report/re-analyze`. |
| `404` | `"O relatório não foi encontrado."` | `id` inexistente. |
