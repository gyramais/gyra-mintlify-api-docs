### Quando usar

Use esta rota para listar os relatórios da organização, do mais recente para o mais antigo, com filtros por documento, status e período. Ela traz o resumo de cada relatório (decisão, política, progresso), sem o conteúdo das seções.

### Autenticação

Bearer JWT no header `Authorization`. Usuários com papel de analista de crédito veem só os relatórios que criaram.

### Parâmetros

| Parâmetro | Tipo | Descrição |
|---|---|---|
| `take` | `number` | Quantos relatórios trazer. Padrão: 20. |
| `skip` | `number` | Quantos pular, para paginar. Padrão: 0. |
| `document` | `string` | CPF ou CNPJ, sem máscara. Precisa ter dígito verificador válido. |
| `statusValue` | `string` | `PENDING`, `APPROVED` ou `REJECTED`, em maiúsculas. |
| `userId` | `string` | Relatórios criados por um usuário. O valor `api-user` traz só os relatórios criados pela API. |
| `createdAtBetween` | `string[]` | Período de criação: duas datas ISO, início e fim. Repita o parâmetro: `createdAtBetween=2026-07-01T00:00:00Z&createdAtBetween=2026-07-31T23:59:59Z`. |
| `reportIds` | `string[]` | IDs específicos de relatório. Repita o parâmetro para cada ID. |

Os filtros se combinam.

```http
GET /report/list?take=2&document=11222333000181
```

Retorna os **2 relatórios mais recentes** do CNPJ **11.222.333/0001-81**.

<RequestExample>

```bash cURL
curl --location 'https://gyra-core.gyramais.com.br/report/list?take=2&document=11222333000181' \
--header 'Authorization: Bearer {seu_token_jwt}'
```

```javascript JavaScript
fetch("https://gyra-core.gyramais.com.br/report/list?take=2&document=11222333000181", {
  headers: {
    Authorization: "Bearer {seu_token_jwt}"
  }
})
  .then(res => res.json())
  .then(console.log)
```

```python Python
import requests

headers = {
    "Authorization": "Bearer {seu_token_jwt}"
}

params = {
    "take": 2,
    "document": "11222333000181"
}

response = requests.get("https://gyra-core.gyramais.com.br/report/list", headers=headers, params=params)
print(response.json())
```

</RequestExample>
