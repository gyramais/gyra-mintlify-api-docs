### Quando usar

Use esta rota quando você quer o link do arquivo na própria resposta. A chamada só volta depois que o arquivo está pronto, então use um timeout generoso no seu cliente HTTP. Para não segurar a conexão, ou para gerar PDF e Excel juntos, use [Exportar Relatório (Assíncrono)](/api-reference/report/get-reportexport).

### Autenticação

Bearer JWT no header `Authorization`.

### Parâmetros

| Nome | Local | Tipo | Obrigatório | Descrição |
|---|---|---|---|---|
| `id` | `path` | `string` | sim | ID do relatório. |
| `type` | `query` | `string` | **sim** | `REPORT` ou `REPORT_MINIFIED`. Use `REPORT`. Sem o parâmetro, a resposta é `400`. |
| `exportFormat` | `query` | `string` | não | `pdf` (padrão) ou `excel`. Nesta rota, `both` não gera arquivo e responde erro: use a rota assíncrona. |
| `sectionOrder` | `query` | `string[]` | não | Seções do arquivo, na ordem desejada. Repita o parâmetro para cada seção. Só as seções listadas entram. |
| `templateId` | `query` | `string` | não | ID de um modelo de exportação da organização. |
| `systemTemplate` | `query` | `string` | não | Modelo nativo: `COMPLETE` ou `COMPACT`. |

Sem `sectionOrder`, valem as seções e a ordem do modelo (o escolhido, senão o padrão da organização, senão o do sistema).

### Resposta

A resposta é o registro da exportação. O link está em `url`.

| Campo | Descrição |
|---|---|
| `url` | Link do arquivo gerado. |
| `payload.reportId` | Relatório exportado. |
| `payload.type` | `PDFMAKE` para PDF, `EXCEL` para Excel. |
| `payload.generatedAt` | Quando o arquivo foi gerado. |
| `id`, `userId`, `organizationId`, `typeId`, `createdAt`, `updatedAt` | Metadados do registro. |

O link também fica gravado no relatório, em `exportUrl` (PDF) ou `exportExcelUrl` (Excel). O link do Excel expira em 7 dias.

<RequestExample>

```bash cURL
curl --request GET 'https://gyra-core.gyramais.com.br/report/export-sync/6612a7f3a19b467000000000?type=REPORT&exportFormat=pdf' \
  --header 'Authorization: Bearer SEU_TOKEN'
```

```bash cURL (com sectionOrder)
curl --request GET 'https://gyra-core.gyramais.com.br/report/export-sync/6612a7f3a19b467000000000?type=REPORT&sectionOrder=LOCATION&sectionOrder=SUMMARY&sectionOrder=PEFIN' \
  --header 'Authorization: Bearer SEU_TOKEN'
```

```javascript JavaScript
const url = new URL("https://gyra-core.gyramais.com.br/report/export-sync/6612a7f3a19b467000000000");
url.searchParams.set("type", "REPORT");
url.searchParams.set("exportFormat", "pdf");

const resposta = await fetch(url, { headers: { Authorization: `Bearer ${token}` } });
const { url: link } = await resposta.json();
```

```python Python
import requests

resposta = requests.get(
    "https://gyra-core.gyramais.com.br/report/export-sync/6612a7f3a19b467000000000",
    headers={"Authorization": f"Bearer {token}"},
    params={"type": "REPORT", "exportFormat": "pdf"},
    timeout=360,
)
link = resposta.json()["url"]
```

<Note>
  A rota responde `202` mesmo no sucesso, com o arquivo já pronto. Trate `202` com `url` preenchida como sucesso. Um relatório inexistente ou de outra organização não gera arquivo e responde erro.
</Note>
