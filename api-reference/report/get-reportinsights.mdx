### Quando usar

Use este endpoint quando você quer **só a leitura interpretada** do relatório: o parecer de cada seção (texto, score, nível de risco e destaques) e o resumo da deliberação do comitê, sem trazer os payloads pesados de integração.

Casos típicos:

- Alimentar um agente de IA ou um LLM do seu lado com contexto barato, em vez de mandar o relatório inteiro.
- Montar uma tela de resumo executivo no seu sistema.
- Verificar se os pareceres já terminaram antes de [convocar o comitê](/api-reference/report/post-reportcommittee).
- Buscar o detalhe depois de receber o webhook `COMMITTEE_FINISHED`.

<Note>
  Para os dados completos do relatório, use [`GET /v2/report/{id}`](/api-reference/report-v2/get-v2report). Para os votos individuais dos agentes e a auditoria da deliberação, use [`GET /committee/deliberations/{reportId}`](/api-reference/committee/get-committeedeliberations).
</Note>

### Autenticação

Bearer JWT no header `Authorization`. Um `id` de outra organização retorna `404`.

### Parâmetros

| Nome | Local | Tipo | Obrigatório | Descrição |
|---|---|---|---|---|
| `id` | `path` | `string` | `sim` | ID do relatório. |
| `section` | `query` | `string` | `não` | Filtra o parecer de **uma** seção. Sem o parâmetro, retorna todos os pareceres concluídos. Um valor que não seja um tipo de seção válido retorna `400`. |

Só estas **21 seções** produzem parecer, e portanto só elas fazem sentido como filtro:

`BASIC_INFORMATION`, `LOCATION`, `RELATIONS`, `SCORE`, `PROCESSES`, `CERTIFICATES`, `LICENSES_AUTHORIZATIONS`, `PEP`, `SANCTIONS`, `MEDIA_EXPOSURE`, `CRIMINAL_RECORD`, `SOCIAL_ASSISTANCE_PROGRAMS`, `SECTOR`, `SCR`, `SCR_SUMMARY`, `PEFIN`, `REFIN`, `PROTESTS`, `BAD_CHECK`, `PAST_DUE_DEBT`, `BALANCE_SHEET`.

<Warning>
  Filtrar por um tipo de seção **que existe mas não produz parecer** (por exemplo `SUMMARY`, `DRE` ou `CREDIT_POLICY`) não é erro: a requisição retorna `200` com `insights` **vazio**. O mesmo vale para uma seção com parecer que ainda não terminou. Lista completa dos tipos e quais recebem parecer em [Consultar Seção por Tipo](/api-reference/report/get-report-section#tipos-de-se%C3%A7%C3%A3o).
</Warning>

### Resposta

O envelope é o mesmo com ou sem filtro; com `section`, o array `insights` vem com um único item.

| Campo | Descrição |
|---|---|
| `reportId` | ID do relatório. |
| `document` | CPF ou CNPJ analisado. |
| `committee.status` | `RUNNING`, `DONE`, `ERROR`, `SKIPPED` ou `null` (comitê nunca convocado). |
| `committee.decision` | `APPROVED`, `REJECTED`, `REQUIRES_ALCADA` ou `NEEDS_INFO`. |
| `committee.result` | Resultado consolidado: síntese do Presidente, opiniões dos agentes, confiança, custo e duração. |
| `committee.at` | Quando a deliberação terminou. |
| `insights[]` | Um item por seção com parecer concluído. |
| `insights[].section` | Tipo da seção. |
| `insights[].score` | Score do parecer daquela seção. |
| `insights[].riskLevel` | Nível de risco atribuído pelo parecer. |
| `insights[].parecer` | Texto do parecer. |
| `insights[].highlights` | Destaques estruturados da seção. |
| `insights[].at` | Quando o parecer foi gerado. |

<Warning>
  Só entram no array as seções com parecer **concluído**. Um relatório ainda em processamento retorna `insights` vazio ou parcial, e `committee.status` `null`. Isso é o esperado, não é erro.
</Warning>

<RequestExample>

```bash cURL
curl --location 'https://gyra-core.gyramais.com.br/report/6612a7f30000000000000001/insights' \
--header 'Authorization: Bearer {seu_token_jwt}'
```

```bash cURL (uma seção)
curl --location 'https://gyra-core.gyramais.com.br/report/6612a7f30000000000000001/insights?section=PROCESSES' \
--header 'Authorization: Bearer {seu_token_jwt}'
```

```javascript JavaScript
fetch("https://gyra-core.gyramais.com.br/report/6612a7f30000000000000001/insights", {
  method: "GET",
  headers: { "Authorization": "Bearer {seu_token_jwt}" },
})
  .then(res => res.json())
  .then(console.log)
```

```python Python
import requests

url = "https://gyra-core.gyramais.com.br/report/6612a7f30000000000000001/insights"
headers = {"Authorization": "Bearer {seu_token_jwt}"}
params = {"section": "PROCESSES"}  # opcional

response = requests.get(url, headers=headers, params=params)
print(response.json())
```
