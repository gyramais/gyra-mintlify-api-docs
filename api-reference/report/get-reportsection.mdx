### Quando usar

Use esta rota quando você já guardou o `id` de uma seção, vindo de `sections[]` do relatório. Se você só tem o ID do relatório, prefira [Consultar Seção por Tipo](/api-reference/report/get-report-section): é uma chamada em vez de duas, e responde `404` claro quando a seção não existe.

### Autenticação

Bearer JWT no header `Authorization`.

### Parâmetros

| Nome | Local | Tipo | Obrigatório | Descrição |
|---|---|---|---|---|
| `id` | `path` | `string` | sim | ID da seção dentro do relatório (não é o ID do tipo de seção). |

### Como obter o `id`

<Warning>
  O `id` desta rota é gerado **por relatório**: a mesma seção `PROCESSES` tem um `id` diferente em cada análise. Não existe lista fixa de ids para guardar.
</Warning>

Os ids vêm em `sections[]` de [`GET /v2/report/{id}`](/api-reference/report-v2/get-v2report):

```json
{
  "id": "6612a7f3a19b467000000000",
  "sections": [
    { "id": "6612a7f3a19b467000000101", "type": { "id": "6612a7f3cd81d4f900000000", "value": "SUMMARY" } },
    { "id": "6612a7f3a19b467000000102", "type": { "id": "6612a7f3cd81d4f900000001", "value": "PROCESSES" } }
  ]
}
```

| Campo | O que é | Estabilidade |
|---|---|---|
| `id` (da seção) | A seção daquele relatório. **É o que vai nesta rota.** | Único por relatório |
| `type.id` | O registro do tipo de seção no catálogo | Varia por ambiente, não use como chave |
| `type.value` | O nome do tipo (`SUMMARY`, `PROCESSES`) | **Estável.** É a chave a guardar no seu lado |

A lista completa de `type.value` está em [Consultar Seção por Tipo](/api-reference/report/get-report-section#tipos-de-se%C3%A7%C3%A3o).

<Note>
  Um `id` que não corresponde a nenhuma seção responde `200` **sem corpo**, e não `404`. Trate resposta vazia como "seção não encontrada".
</Note>

<RequestExample>

```bash cURL
curl --request GET 'https://gyra-core.gyramais.com.br/report/section/6612a7f3dc5b830500000000' \
  --header 'Authorization: Bearer SEU_TOKEN'
```

```javascript JavaScript
const resposta = await fetch(
  "https://gyra-core.gyramais.com.br/report/section/6612a7f3dc5b830500000000",
  { headers: { Authorization: `Bearer ${token}` } },
);
const secao = await resposta.json();
```

```python Python
import requests

resposta = requests.get(
    "https://gyra-core.gyramais.com.br/report/section/6612a7f3dc5b830500000000",
    headers={"Authorization": f"Bearer {token}"},
)
secao = resposta.json()
```

</RequestExample>
