### Quando usar

Use esta rota para ler o resultado de um relatório criado em [`POST /v2/report`](/api-reference/report-v2/post-v2report): status da decisão, progresso do processamento e o conteúdo de todas as seções. Para ler uma seção só, use [Consultar Seção por Tipo](/api-reference/report/get-report-section). Para ler só os pareceres, use [`GET /report/{id}/insights`](/api-reference/report/get-reportinsights).

### Autenticação

Bearer JWT no header `Authorization`. A credencial precisa da permissão de leitura de relatórios pela API. Um `id` de outra organização responde `404`.

### Parâmetros

| Nome | Local | Tipo | Obrigatório | Descrição |
|---|---|---|---|---|
| `id` | `path` | `string` | sim | ID do relatório devolvido em `POST /v2/report`. |

A rota não aceita filtros: a resposta traz sempre todas as seções, com o conteúdo.

### Resposta

| Campo | Descrição |
|---|---|
| `status.value` | Decisão do relatório: `PENDING`, `APPROVED` ou `REJECTED`. |
| `reportProgress.isFinalized` | `true` quando todas as fontes terminaram. `finalizedAt` traz a data. |
| `sections[]` | Uma entrada por seção: `id`, `type` (`id`, `title`, `value`), `sectionDetails[]` (`values` e `errors`), `errors`, o comentário mais recente em `comments[]` e os campos do Parecer IA (`parecer`, `parecerScore`, `parecerRiskLevel`, `parecerStatus`, `parecerFeedback`). |
| `policyId`, `policyName`, `policyVersion` | Política aplicada. |
| `analystId`, `analystName`, `commentary` | Decisão manual, quando houver. |
| `parecerEnabled` | Se o relatório gera Parecer IA por seção. |
| `committeeStatus`, `committeeDecision`, `committeeResult` | Resultado do Comitê de Crédito IA, quando convocado. |
| `exportUrl`, `exportExcelUrl` | Último arquivo exportado (PDF e Excel), ou `null`. |

O nome de cada fonte de dado não vem na resposta: os dados aparecem já organizados por seção.

<RequestExample>

```bash cURL
curl --request GET 'https://gyra-core.gyramais.com.br/v2/report/6612a7f3a19b467000000000' \
  --header 'Authorization: Bearer SEU_TOKEN'
```

```javascript JavaScript
const resposta = await fetch(
  "https://gyra-core.gyramais.com.br/v2/report/6612a7f3a19b467000000000",
  { headers: { Authorization: `Bearer ${token}` } },
);
const relatorio = await resposta.json();
```

```python Python
import requests

resposta = requests.get(
    "https://gyra-core.gyramais.com.br/v2/report/6612a7f3a19b467000000000",
    headers={"Authorization": f"Bearer {token}"},
)
relatorio = resposta.json()
```

</RequestExample>
