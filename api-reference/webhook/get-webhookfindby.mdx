### Quando usar

Use esta rota para listar os webhooks cadastrados na sua organização: tipo, URL e `apiKey` de cada um. Serve para auditar a configuração antes de criar ou remover um webhook.

### Autenticação

Bearer JWT no header `Authorization`.

### Parâmetros

| Nome | Local | Tipo | Obrigatório | Descrição |
|---|---|---|---|---|
| `webhookId` | `query` | `string` | não | ID de um webhook. Sem o parâmetro, a resposta traz todos os webhooks da organização do token. |

A resposta é sempre um array, mesmo com `webhookId`. Se a consulta falhar, a resposta é `200` sem corpo.

<RequestExample>

```bash cURL
curl --location 'https://gyra-core.gyramais.com.br/webhook/findBy' \
--header 'Authorization: Bearer {seu_token_jwt}'
```

```javascript JavaScript
fetch("https://gyra-core.gyramais.com.br/webhook/findBy", {
  method: "GET",
  headers: {
    "Authorization": "Bearer {seu_token_jwt}",
  },
})
  .then(res => res.json())
  .then(console.log)
```

```python Python
import requests

url = "https://gyra-core.gyramais.com.br/webhook/findBy"
headers = {
  "Authorization": "Bearer {seu_token_jwt}"
}
response = requests.get(url, headers=headers)
print(response.json())
```
