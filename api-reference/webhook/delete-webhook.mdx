### Quando usar

Use esta rota para remover um webhook, por exemplo ao trocar a URL de destino. A remoção é definitiva e a URL para de receber eventos. Para trocar a URL, remova e cadastre de novo em [Criar Webhook](/api-reference/webhook/post-webhook).

### Autenticação

Bearer JWT no header `Authorization`.

### Parâmetros

| Nome | Local | Tipo | Obrigatório | Descrição |
|---|---|---|---|---|
| `id` | `path` | `string` | sim | ID do webhook, de [Consultar Webhook](/api-reference/webhook/get-webhookfindby). |

A resposta traz o webhook removido.

<RequestExample>

```bash cURL
curl --location --request DELETE 'https://gyra-core.gyramais.com.br/webhook/6612a7f32f90990d00000000' \
--header 'Authorization: Bearer {seu_token_jwt}'
```

```javascript JavaScript
fetch("https://gyra-core.gyramais.com.br/webhook/6612a7f32f90990d00000000", {
  method: "DELETE",
  headers: {
    "Authorization": "Bearer {seu_token_jwt}",
  },
})
  .then(res => res.json())
  .then(console.log)
```

```python Python
import requests

url = "https://gyra-core.gyramais.com.br/webhook/6612a7f32f90990d00000000"
headers = {
  "Authorization": "Bearer {seu_token_jwt}"
}
response = requests.delete(url, headers=headers)
print(response.json())
```

</RequestExample>
