### Quando usar

Chame esta rota no início da integração para obter o token que vai no header `Authorization` de todas as outras chamadas. O token vale **24 horas** a partir da emissão (campo `expiresAt`). Gere um novo antes de expirar.

### Autenticação

A rota é pública: não exige token. As credenciais vão em dois headers. Gere o par em **Configurações**, **API & MCP**, conforme [Chaves de API](/api-reference/api-keys).

### Parâmetros

| Nome | Local | Tipo | Obrigatório | Descrição |
|---|---|---|---|---|
| `gyra-client-id` | `header` | `string` | sim | Client ID da credencial. |
| `gyra-client-secret` | `header` | `string` | sim | Client Secret da credencial, mostrado uma única vez na criação. |

O corpo da requisição é ignorado.

### Resposta

| Campo | Descrição |
|---|---|
| `accessToken` | Token JWT. Envie como `Authorization: Bearer <accessToken>`. |
| `expiresAt` | Data e hora em que o token deixa de valer (24 horas após a emissão). |
| `id` | ID da sessão criada. |
| `userId` | ID do usuário técnico da credencial. |
| `organizationId` | Organização dona da credencial. Todas as chamadas feitas com o token ficam restritas a ela. |
| `loggedOutAt` | Sempre `null` na emissão. |
| `createdAt` / `updatedAt` | Datas de criação da sessão. |

<RequestExample>

```bash cURL
curl --request POST 'https://gyra-core.gyramais.com.br/auth/authenticate' \
  --header 'gyra-client-id: SEU_CLIENT_ID' \
  --header 'gyra-client-secret: SEU_CLIENT_SECRET'
```

```javascript JavaScript
const resposta = await fetch("https://gyra-core.gyramais.com.br/auth/authenticate", {
  method: "POST",
  headers: {
    "gyra-client-id": process.env.GYRA_CLIENT_ID,
    "gyra-client-secret": process.env.GYRA_CLIENT_SECRET,
  },
});
const { accessToken, expiresAt } = await resposta.json();
```

```python Python
import requests

resposta = requests.post(
    "https://gyra-core.gyramais.com.br/auth/authenticate",
    headers={
        "gyra-client-id": client_id,
        "gyra-client-secret": client_secret,
    },
)
token = resposta.json()["accessToken"]
```

</RequestExample>

### Erros

| Código | Mensagem | Causa |
|---|---|---|
| `400` | `"ClientId inválido."` | O `gyra-client-id` não corresponde a nenhuma credencial (inclusive credencial revogada). |
| `401` | `"ClientSecret inválido."` | O `gyra-client-secret` não confere com o client id. |
| `401` | `"Token de acesso inválido."` | Resposta das **outras** rotas quando o token está ausente, malformado ou expirado. Gere outro aqui. |
